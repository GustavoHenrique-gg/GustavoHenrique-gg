## 🎮 Desafio para você!

🕹️ **Vamos jogar! Descubra onde está o bug escondido!**

> Você está caminhando pelo código e encontra três caminhos:
> 
> 🛤️ Caminho 1: `./frontend`  
> 🛤️ Caminho 2: `./backend`  
> 🛤️ Caminho 3: `./database`  
> 
> Qual você escolhe para procurar o bug?  
> 👉 Digite o número: `1`, `2` ou `3`  

<details>
<summary>🔍 Ver a resposta</summary>

- 🛤️ **Caminho 1 (`./frontend`)**  
Você encontrou um erro de CSS quebrando o layout! Nada grave, bora arrumar!

- 🛤️ **Caminho 2 (`./backend`)**  
Parabéns! Você achou um bug no backend: uma API retornando `null` inesperadamente. Missão concluída! 🚀

- 🛤️ **Caminho 3 (`./database`)**  
Oops... Um erro de conexão no banco de dados te derrubou! Parece que alguém esqueceu de configurar o `.env`. 😅

</details>
